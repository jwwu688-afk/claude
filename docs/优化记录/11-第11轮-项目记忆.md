## 一、为什么需要它

模型每轮都是"第一次来"。不告诉它这个项目的规矩，它就会：

- 在中文注释的项目里写英文注释
- 改完代码不跑测试
- 随手引入一个新依赖（而这个项目故意保持轻量）

这些事以前只能靠用户在对话里反复说。写进 `THINKER.md` 之后，每次请求都自动带在系统提示词里。

`prompt_manager.py` 第 7 轮留的注释就写着"以后要加项目说明文件（比如 THINKER.md）"——这一轮把它填上了。

## 二、查找顺序：越靠近现场，优先级越高

```
~/.thinker/THINKER.md          全局，最先加载（优先级最低）
D:\THINKER.md
D:\code\THINKER.md
D:\code\thinker\THINKER.md     当前目录，最后加载（优先级最高）
```

和 CSS 的层叠一个道理：越晚出现的越"贴近现场"，冲突时以后者为准。

两个细节：

- **向上最多找 6 层**。不限层数的话，从 `D:\code\thinker` 会一路找到 `D:\`，万一那里躺着一个 `THINKER.md` 会很莫名。
- **不存在的文件直接跳过**，不会在提示词里留下空洞。

## 三、`@import`：把长文档拆开

主文件里单独一行写 `@docs/规范.md`，会把这个文件的内容嵌进来：

```markdown
## 编码规范

@docs/coding-style.md

## 提交规范

@docs/git-conventions.md
```

三个约束：

| 约束 | 值 | 为什么 |
|---|---|---|
| 递归深度 | 3 层 | 防止"引用的文件又引用回来"绕不出来 |
| 循环检测 | 记录已访问路径 | 同上，但这是硬保证，深度只是兜底 |
| 单文件上限 | 12000 字符 | 超了截断，并在正文里写明"已截断 N 字符，需要全文请读 <路径>" |

最后那条的写法有讲究：**必须告诉模型"这里被截断了"**。只给半截规则，它会以为"就这些"，可能违反后半段里真正重要的约束。

## 四、注入位置：规矩 → 记忆 → 环境

```text
sections = [get_system_rule()]        # 身份、安全底线
memory = load_project_memory()
if memory:
    sections.append(memory)           # 项目约定
sections.append(get_enviroment_info())  # 今天几号、在哪个目录
```

为什么记忆放中间：

- 规矩必须**最先**立住（身份和安全底线不能被子目录的约定覆盖）
- 环境信息放**最后**：模型每轮都要引用"当前目录""今天日期"，尾部更容易被取到
- 记忆是一整块"项目特有"的内容，夹在中间不和前后冲突

没有记忆文件时整段跳过——否则系统提示词里会出现"以下是项目记忆：（空）"这种废话，白占 token。

## 五、`--init`：生成能直接用的骨架

```bash
thinker --init          # 已存在则跳过
thinker --init --force  # 覆盖重写
```

生成时自动填好**技术栈**（看 `pyproject.toml` / `package.json` / `go.mod` / `Cargo.toml` / `pom.xml`）和**目录树**（两层、最多 24 项，跳过 `.git` / `node_modules` / `__pycache__` 等）。

留空的是「代码约定」「不要做的事」「已知的坑」三节——这三样机器猜不出来，必须人写，所以模板里给了具体的填写示例，而不是一句"请补充"。

> 为什么挂在命令行参数而不是 `/init` 斜杠命令：斜杠命令系统（第 12 轮）还没做，这一步不该等它。

## 七、遗留

| 编号 | 问题 | 计划 |
|---|---|---|
| M1 | 子目录的 `THINKER.md` 是启动时一次性加载的，模型中途 `cd` 到别处不会重新加载 | Claude Code 2.x 有"按需懒加载"，等有了 `cd` 语义再做 |
| M2 | 没有 `/init` 斜杠命令，只能 `thinker --init` | 第 12 轮斜杠命令系统一起做 |
| M3 | 记忆不参与缓存断点优化：它每轮都在系统提示词里，占固定 token | 已经和系统提示词一起被缓存命中，实测命中率 99%，不用单独优化 |
| M4 | 没有"记忆冲突提示"：父目录和子目录写了相反的规则时，模型只能自己按"后者优先"判断 | 够用，暂不做 |
