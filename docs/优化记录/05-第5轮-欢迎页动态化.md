## 二、具体做了什么

### 2.1 大号标题：手写 5×5 字模

`src/main.py` 新增 `_GLYPHS`，把 Q、U、I、C、K、S、T、A、R 九个字母各自画成 5 行方块：

```python
"Q": [" ███ ", "█   █", "█   █", "█  ██", " ████"],
"U": ["█   █", "█   █", "█   █", "█   █", " ███ "],
...
```

`_build_logo_lines()` 把它们拼成 5 行等宽文字（宽 54 列），并且**每个字母之间留 1 个空格**。

> **这里踩了一个坑**：第一版忘了留空格，`T` 的右边缘和 `H` 的左边缘直接贴在一起，`██ ██` 连成一片，整个标题糊成一团。加上间距后才认得出是 THINKER。

### 2.2 渐变：HSV 色相环取色

`src/ui/theme.py` 新增 `gradient_color(index, total, dim)`：

```python
hue = 0.5 + (index / (total - 1)) * 0.62   # 0.5 青色 → 1.12 绕回 0.12 红橙
r, g, b = colorsys.hsv_to_rgb(hue, 0.72, 0.62 if dim else 1.0)
return f"rgb({int(r*255)},{int(g*255)},{int(b*255)})"
```

为什么用 HSV 而不是手挑几个 RGB：色相 H 是一个 0~1 的环，从 0.5 线性走到 1.12 就会自动经过青→蓝→紫→洋红→红，比手动插值省事且过渡均匀。

`dim=True` 会压暗明度，用在分隔线和装饰带的小点上——它们不该和标题抢注意力。

### 2.3 扫光动画

```python
with Live(console=console, auto_refresh=False, transient=False) as live:
    for start in range(-9, _LOGO_WIDTH + 9, 3):
        live.update(_logo_text(highlight_start=start), refresh=True)
        time.sleep(0.025)
    live.update(_logo_text(highlight_start=None), refresh=True)
```

- 高光带宽 9 列，从屏幕左侧外扫到右侧外，共约 24 帧、0.4 秒
- 最后一帧切换成"纯渐变"（不再有白带），停住
- 每帧只改变"哪几列是白色"，字符内容完全相同，所以不会闪烁

**自动跳过动画的两种情况**（`_should_animate()`）：

1. 输出不是终端（被重定向到文件、被程序捕获）——否则动画会变成一屏乱码
2. 设了环境变量 `THINKER_NO_ANIM=1`

### 2.4 装饰元素

| 元素 | 实现 |
|---|---|
| 顶部星形带 | `_star_strip()`：`✦ · ✧ ·` 循环 19 个符号，逐个取渐变色；圆点用暗色、星形加粗 |
| 上下分隔线 | `_gradient_rule()`：`✦ ─────…───── ✦`，横线用 `dim` 渐变，两端星形用亮色 |
| 面板 | 去掉了第 4 轮那个方框——大标题本身就是视觉主体，再加框反而啰嗦 |

宽度全部按 `console.width` 自适应：标题居中的留白、分隔线的长度都跟着终端宽度算，换窄终端也不会折行。

### 2.5 对话区也加了颜色（不只是欢迎页）

| 位置 | 改动 |
|---|---|
| 状态行 `⎿` | 符号改成青色加粗，和正文拉开层次 |
| 上下文水位 | `<50%` 暗灰、`50~75%` 黄色、`>75%` 红色——快满了会自己"跳"出来 |
| 工具结果 `⎿` | 同样青色加粗，失败时正文转红 |

## 五、已知遗留

| 编号 | 问题 | 说明 |
|---|---|---|
| U1 | 不支持真彩色的终端会显示成近似色 | Windows 10 之前的 conhost 可能不支持 `rgb()`，会退回 256 色附近 |
| U2 | 标题固定 5 行，终端高度不足时会挤掉输入行 | 高度 <15 行的终端建议设 `THINKER_NO_ANIM=1` 并考虑换终端 |
| U3 | 花费仍恒为 $0 | 接口不返回 `usage.model_extra.cost`，与界面无关 |
| U4 | 没有"正在思考"的转圈 | 回车后到模型开口之间有 1-3 秒空档，可加 `rich.spinner` |
